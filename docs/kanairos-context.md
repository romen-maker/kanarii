# Kanarii en el Ecosistema KanAIrOS

## Qué es KanAIrOS

KanAIrOS es un sistema operativo para comunidades autosuficientes, conscientes
y regenerativas. Su misión es crear infraestructura digital y física que permita
a comunidades de propósito construir autosuficiencia real, delegando en la IA la
carga operativa sin ceder la voluntad humana ni la identidad comunitaria.

KanAIrOS es el ecosistema. Kanarii es uno de sus nodos.

## Qué es Kanarii dentro de KanAIrOS

Kanarii es el módulo de gestión comunitaria de KanAIrOS. Se ocupa de:

- Creación y gestión de comunidades
- Propuestas y votaciones con quórum
- Incorporación y roles de miembros
- Onboarding comunitario

Es el primer nodo activo del ecosistema y el punto de partida para validar
la infraestructura de agentes que KanAIrOS necesita a mayor escala.

## Cómo se relacionan

Las directivas en `.agents/` de este repositorio están diseñadas bajo los
valores de KanAIrOS: horizontalidad, transparencia radical y tecnología al
servicio de la comunidad.

Cuando el ecosistema KanAIrOS tenga repositorio propio, este documento se
actualizará con el enlace correspondiente.
