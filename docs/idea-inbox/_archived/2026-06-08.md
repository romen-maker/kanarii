#### 2. Diagnóstico de Problemas Detectados
1. **Pérdida de Visibilidad del Admin (Riesgo Crítico)**: Los nuevos miembros que ingresan a Kanarii y generan su manual bajo el sistema modular de T-060 no escriben en `manualGenerado`. El admin verá sus expedientes como vacíos de manual, a menos que el expediente se actualice para leer de las nuevas secciones.
2. **Duplicidad de Vistas de Pestañas**: `FichaView.tsx` renderiza las secciones usando una interfaz propia con pestañas, mientras que `ManualViewer.tsx` (usado por el admin) implementa otra lógica de navegación e iconos por separado.
3. **Mapeos Fallback Redundantes**: Hay múltiples funciones de fallback redundantes para leer campos básicos (`nombre`, `saberes`, `rol`) repartidas en las distintas vistas debido al histórico de cambios del onboarding.

#### 3. Propuesta de Arquitectura Objetivo
1. **Visor Híbrido Reutilizable**: Crear un componente compartido `<ManualSeccionesViewer>` que reciba un objeto de tipo secciones (clave-valor de narrativa) y lo renderice. Este componente consumirá por prioridad `resumenManual.secciones` y, si está ausente, aplicará el parseador regex sobre `manualGenerado` como fallback.
